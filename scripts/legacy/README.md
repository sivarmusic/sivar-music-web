# Esquema legacy de Pink Fest

Estos scripts documentan las tablas `pinkfest_orders`, `pinkfest_tickets`,
`pinkfest_settings` y `pinkfest_visits`.
Las tablas siguen existiendo en Supabase (no se borraron), pero el código
de la aplicación ya no las usa desde que se eliminó el módulo Pink Fest.
Se conservan solo como documentación del esquema; no hay que volver a ejecutarlos.
